# Autorização de publicação

HideXs, criador original do AscensionES, concedeu autorização expressa para a publicação e distribuição gratuita da adaptação brasileira no GitHub.

A autorização permite:

- traduzir;
- revisar;
- adaptar;
- publicar;
- distribuir gratuitamente a versão em Português do Brasil.

A autorização está condicionada a:

1. manter crédito claro a HideXs como criador original;
2. declarar que o projeto é baseado no AscensionES;
3. incluir link para o repositório original;
4. deixar claro que se trata de uma adaptação comunitária não oficial;
5. manter o projeto gratuito e não comercial;
6. preservar os créditos e notas de autoria originais.
