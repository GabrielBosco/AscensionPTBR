# Política de segurança

Este projeto é um addon comunitário e não executa instaladores.

Baixe arquivos apenas pela página oficial de Releases deste repositório.

Não distribua versões modificadas como se fossem oficiais e não inclua executáveis, instaladores ou arquivos desconhecidos dentro do pacote do addon.

Para relatar comportamento suspeito, abra uma Issue ou entre em contato de forma privada com o mantenedor.
