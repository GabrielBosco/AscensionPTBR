# AscensionPTBR 1.4.0 — Revisão do sistema de missões

## Interface de missões

- Tradução dedicada para os cabeçalhos, rótulos e botões das janelas de missão.
- `Objectives` agora é exibido como **Objetivos**.
- `Quests` agora é exibido como **Missões**.
- Tradução de descrição, progresso, recompensas, itens necessários e escolhas de recompensa.
- Tradução dos botões Aceitar, Recusar, Continuar, Concluir, Abandonar e Compartilhar missão.
- Suporte ao Registro de Missões clássico e aos painéis personalizados de objetivos do Ascension.
- Monitoramento dos textos recriados pelo servidor para evitar que voltem ao inglês.

## Base de quests

- 14.078 títulos de missões verificados.
- 13.987 registros de missões verificados.
- 59.167 campos traduzidos analisados.
- 1.965 campos corrigidos nesta revisão.
- 98 divergências numéricas corrigidas entre o texto inglês e a tradução.
- Correções de espanhol residual, portunhol, concordância e palavras corrompidas.
- Textos ingleses de referência, IDs, placeholders e estrutura Lua preservados.

## Otimização

- A tradução de quests não depende mais da varredura geral da interface.
- Somente os quadros relacionados a missões são percorridos.
- Quadros repetidos são ignorados na mesma passagem.
- Os FontStrings são monitorados após a primeira tradução, permitindo corrigir alterações posteriores do Ascension sem varrer toda a interface.
